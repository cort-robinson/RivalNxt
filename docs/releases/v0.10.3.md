# RivalNxt v0.10.3

Mod update checks are faster and keep the library state accurate after downloads.

- Check up to three unique Nexus mods concurrently, with a shared request cap and rate-limit cooldown handling.
- Fetch only mod details and files during update checks, avoiding an unnecessary changelog request per mod.
- Show one update-list entry per mod, with separate pending file variants beneath it. Download each target file only once.
- Record the exact Nexus file associated with successful downloads. Keeping an older archive no longer leaves the same downloaded update pending.
- Follow explicit Nexus file replacement links, including renamed files and replacements that reuse a version number.
- Refresh update results after completed downloads and ignore older overlapping library responses.
- Preserve cached metadata on failed checks and show errors instead of reporting that everything is current.

Existing archives are retained. These changes track downloaded updates; activating a downloaded mod remains a separate action.
