## Complete legacy backup restores

- Restore a legacy JSON backup's mod selection, descriptions, custom tags, artwork and author assignments as one guarded operation. Metadata errors roll back the file selection and leave the previous metadata intact.
- Validate metadata and installed mod identities before touching game files. Changes made after preview require a fresh review; edits made during restoration are preserved when the restore is rejected.
- Recover interrupted metadata restores using a durable database commit record. An interruption before the metadata commit restores the previous selection; an interruption after it preserves the completed restore.
- Restore metadata even when the selected mod files already match. Repeated restores merge tags and artwork without duplicates and retain the exact saved artwork bytes.
- Both legacy backup dialogs use the same preview and transaction. Full Snapshot ZIP restore behavior is unchanged.

Recovery continues to pause if an interrupted file copy or later external edits cannot be verified safely. The original journal and file copies remain available for review.

The release workflow verifies source checks, the frozen backend, the updater signature, and Windows upgrade/reinstall behavior before publication. Updater signatures are separate from Windows Authenticode publisher signing.
