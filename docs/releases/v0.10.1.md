## Safer switching and clearer recovery

- Preview exactly which files a preset enables and disables before applying it. Missing downloads and changed source identities block the switch.
- Apply a preset as one guarded batch, with verified rollback copies and stale-preview detection. Failed switches attempt to restore the previous files and database selection.
- Interrupted switches remain visible after restarting. Further mod changes pause until recovery is reviewed. Recovery refuses to overwrite later edits or guess what happened during an interrupted copy; original files and the journal remain available for manual recovery.
- Group conflicts by their existing character/skin tags and choose **Keep this variant** to review the competing files that will be disabled.

## Activity and post-patch review

- **Activity** combines download progress, cancellation, import/activation/backup results, and durable failed or interrupted operation history.
- Failed Nexus downloads link to the mod's Files page for a fresh download request. Expired download credentials are not replayed.
- **Health check** reviews game-file changes, package integrity, missing companions, and available recovery options. Open it from the header or after game-update processing.
- Package integrity remains separate from **in-game compatibility: unknown**. A successful scan does not establish that a mod works with the current game patch.

## Diagnostics and app updates

- Preview and save a bounded diagnostics report containing versions, recent operations, and available logs. Credentials, URLs, email addresses, and local paths are redacted; nothing is shared automatically.
- Check for app updates from **cort-robinson/RivalNxt**, read release notes, and choose when to install. A successful safety backup is required before downloading and installing a signed update.
- v0.9.0 users must install this release manually once to receive the in-app updater.

## Release verification

The release workflow runs backend and frontend checks, builds the Windows installer, verifies its update signature, and exercises upgrade/reinstall and backend startup on an isolated Windows runner before publication. Release assets include the installer, SHA-256 checksum, updater signature, and update manifest.

Updater signatures verify updates inside RivalNxt; they are separate from Windows Authenticode publisher signing.

Full changes: https://github.com/cort-robinson/RivalNxt/compare/v0.9.0...v0.10.1

This release also pins the Tauri JavaScript API and updater to the Rust minor versions and checks their alignment before the native build.
